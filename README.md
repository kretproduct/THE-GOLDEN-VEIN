# The Golden Vein

Статический сайт из четырёх страниц: `index.html` (главная), `community.html` (комьюнити и ниша), `proofs.html` (пруфы), `cases.html` (кейсы учеников).
Сборка не нужна — достаточно открыть `index.html` или выложить папку на любой хостинг.

## Как добавить контент

- **Тексты главной** — прямо в `index.html` (блоки помечены «Здесь будет ваш текст»).
- **Комьюнити и ниша** — тексты прямо в `community.html`.
- **Пруфы** — положить картинки в `assets/img/proofs/` и перечислить их в `assets/js/content.js` (`proofs`).
- **Кейсы** — заполнить список `cases` в `assets/js/content.js`; фото и скриншоты — в `assets/img/cases/`.
- **Кнопка «Связаться»** — ссылка `contact.url` в `assets/js/content.js`.
